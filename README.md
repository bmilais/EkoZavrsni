# EkoZavrsni

Minimalni PHP MVC skeleton (PSR-4) + Oracle (PDO_OCI).

## Pokretanje (XAMPP)
- URL:    http://localhost/EkoZavrsni/public
- Health: http://localhost/EkoZavrsni/public/health.php
- DB:     http://localhost/EkoZavrsni/public/db-check

## Preduvjeti
- PHP pdo_oci ekstenzija (zahtijeva Oracle Instant Client - Basic + php_pdo_oci.dll u ext/ mapi)
- Oracle baza (radi se protiv postojece sheme, init.sql/seed.sql se pokrecu odvojeno)
